# vul-labs 用户故事与验收标准

> 关联：[PRD](./PRD.md) · [Backlog](./backlog.md)
> 格式：每个故事有唯一 ID（US-xxx），验收标准用 Given / When / Then。ID 贯穿 PRD → 设计 → API → 测试，作为可追溯的事实来源。
> 优先级标注：P0 = MVP 必须；P1 = MVP 后紧随；P2 = 远期。

---

## 模块一：账号与鉴权

### US-001 用户注册 `P0`
**作为** 一名安全初学者，**我想要** 用用户名/邮箱和密码注册账号，**以便** 保存我的练习进度。

**验收标准**
- [ ] Given 我在注册页填写合法用户名与符合强度要求的密码，When 我提交，Then 账号创建成功并自动进入登录态（或跳转登录页）。
- [ ] Given 用户名/邮箱已存在，When 我提交，Then 返回明确的"已被注册"错误，不创建重复账号。
- [ ] Given 密码不满足强度要求（如 < 8 位），When 我提交，Then 返回校验错误并提示规则。
- [ ] Given 注册成功，Then 密码以加盐哈希存储，数据库中不存在明文密码。
- [ ] 安全：注册接口对同一 IP 有频率限制，防批量注册。

### US-002 用户登录 `P0`
**作为** 一名注册用户，**我想要** 登录平台，**以便** 访问靶场和我的进度。

**验收标准**
- [ ] Given 我输入正确的账号密码，When 我提交登录，Then 登录成功并建立会话，跳转到靶场列表。
- [ ] Given 我输入错误的密码，When 我提交，Then 返回"账号或密码错误"（不区分是账号还是密码不存在，防枚举）。
- [ ] Given 连续多次登录失败（如 5 次），When 再次尝试，Then 触发限流/锁定，防暴力破解。
- [ ] Given 登录成功，Then 会话凭证为 HttpOnly Cookie 或安全 Token，并具备过期时间。

### US-003 登出与会话保持 `P0`
**作为** 一名已登录用户，**我想要** 安全登出，**以便** 在公共环境保护我的账号。

**验收标准**
- [ ] Given 我已登录，When 我点击登出，Then 服务端会话失效，再访问需鉴权的页面会被重定向到登录。
- [ ] Given 会话已过期，When 我访问受保护资源，Then 返回 401 并引导重新登录。
- [ ] Given 我携带他人/伪造的会话凭证，When 访问，Then 鉴权失败。

## 模块二：靶场目录与详情

### US-010 浏览靶场列表 `P0`
**作为** 一名用户，**我想要** 看到所有可用靶场的列表，**以便** 选择要练习的目标。

**验收标准**
- [ ] Given 平台已有种子靶场，When 我进入列表页，Then 看到每个靶场的名称、漏洞类型、难度、以及我的通关状态（未开始/已通关）。
- [ ] Given 列表为空，When 我进入，Then 显示友好的空状态提示。
- [ ] Given 列表加载中，Then 显示加载态而非空白。
- [ ] 性能：100 个靶场以内首屏 < 1.5s。

### US-011 按类型与难度筛选靶场 `P0`
**作为** 一名 CTF 选手，**我想要** 按漏洞类型和难度筛选靶场，**以便** 高效地刷我想练的题。

**验收标准**
- [ ] Given 我在列表页选择"类型=SQL 注入"，When 应用筛选，Then 仅显示该类型靶场。
- [ ] Given 我同时选择"类型=XSS"和"难度=入门"，When 应用，Then 显示同时满足两个条件的靶场。
- [ ] Given 筛选结果为空，When 应用，Then 显示"无匹配靶场"并提供清除筛选入口。
- [ ] Given 我清除筛选，Then 恢复显示全部靶场。

### US-012 查看靶场详情 `P0`
**作为** 一名用户，**我想要** 查看靶场的描述、目标和提示，**以便** 理解任务并开始攻击。

**验收标准**
- [ ] Given 我点击某个靶场，When 进入详情页，Then 看到靶场描述、攻击目标、难度、漏洞类型、提示（可折叠）和"启动环境"入口。
- [ ] Given 该靶场我已通关，When 进入详情，Then 显示已通关标记与通关时间。
- [ ] Given 靶场暂不可用（维护/镜像缺失），When 进入，Then 启动入口禁用并提示原因。
- [ ] 安全：详情页与任何接口都不返回正确 flag。

## 模块三：靶场实例引擎（沙箱）

### US-020 按需启动靶场实例 `P0`
**作为** 一名用户，**我想要** 一键启动靶场环境，**以便** 拿到一个可被我攻击的独立实例。

**验收标准**
- [ ] Given 我在靶场详情页点击"启动环境"，When 实例创建成功，Then 我获得一个专属访问地址（URL/端口），并显示实例剩余有效时间。
- [ ] Given 镜像已就绪，When 我启动，Then P95 < 30s 内拿到可访问地址。
- [ ] Given 我已有一个该靶场的运行中实例，When 我再次点击启动，Then 复用现有实例而非重复创建（或先提示）。
- [ ] 隔离：Given 实例已启动，Then 该实例为独立容器、有 CPU/内存/磁盘配额、且无法访问平台内网/DB/宿主元数据服务。
- [ ] 隔离：Given 另一个用户启动同一靶场，Then 二者实例相互隔离、不可互访。

### US-021 访问并攻击靶场实例 `P0`
**作为** 一名用户，**我想要** 通过专属地址访问我的实例，**以便** 实际进行漏洞攻击练习。

**验收标准**
- [ ] Given 实例运行中，When 我访问专属地址，Then 能打开靶场应用并进行交互（靶场内的"漏洞"按设计可被利用）。
- [ ] Given 实例属于其他用户，When 我尝试访问，Then 被拒绝（鉴权/网络隔离）。
- [ ] Given 实例已销毁/过期，When 我访问旧地址，Then 返回不可用提示。

### US-022 实例超时自动销毁 `P0`
**作为** 平台运营者（系统行为），**我想要** 闲置实例被自动回收，**以便** 防止资源耗尽并保证隔离。

**验收标准**
- [ ] Given 实例超过配置的空闲超时（如 60 分钟），When 到达时限，Then 实例被自动销毁、资源释放、访问地址失效。
- [ ] Given 实例被销毁，Then 其内部数据一并清除，不残留、不复用给其他用户。
- [ ] Given 实例即将到期，When 临近超时，Then 前端给出剩余时间提示（可选续期入口为 P1）。

### US-023 手动销毁 / 重置实例 `P1`
**作为** 一名用户，**我想要** 手动销毁或重置我的实例，**以便** 从干净状态重新练习。

**验收标准**
- [ ] Given 我有运行中实例，When 我点击"销毁"，Then 实例被回收、地址失效。
- [ ] Given 我点击"重置"，When 操作完成，Then 获得一个全新的干净实例（旧实例被回收）。
- [ ] Given 我对不属于自己的实例发起销毁，Then 被拒绝。

## 模块四：Flag 与计分

### US-030 提交 flag 并通关计分 `P0`
**作为** 一名用户，**我想要** 提交我攻击得到的 flag，**以便** 验证通关并获得分数。

**验收标准**
- [ ] Given 我在靶场页提交正确的 flag，When 服务端校验通过，Then 记录该靶场为"已通关"、累加分数，并给出成功反馈。
- [ ] Given 我提交错误的 flag，When 校验失败，Then 返回"flag 错误"且不计分、不记录通关。
- [ ] Given 我重复提交已通关靶场的正确 flag，When 提交，Then 不重复加分（幂等）。
- [ ] 安全：Given 任意请求，Then 正确 flag 仅在服务端比对，前端/接口响应中不出现正确 flag。
- [ ] 安全：Given 短时间内大量提交，When 超过阈值，Then 触发限流，防 flag 爆破。

### US-031 计分规则与分数展示 `P0`
**作为** 一名用户，**我想要** 看到每个靶场的分值和我的累计得分，**以便** 衡量练习成果。

**验收标准**
- [ ] Given 靶场配置了难度对应分值，When 我通关，Then 按该靶场分值计入总分。
- [ ] Given 我查看个人中心，Then 看到与通关记录一致的总分（数据一致性）。

## 模块五：个人中心

### US-040 查看个人进度 `P0`
**作为** 一名用户，**我想要** 查看我已通关的靶场、总分和最近活动，**以便** 跟踪自己的学习进展。

**验收标准**
- [ ] Given 我已通关若干靶场，When 进入个人中心，Then 看到已通关靶场列表、总得分、通关数/总靶场数。
- [ ] Given 我尚未通关任何靶场，When 进入，Then 显示鼓励性的空状态与"去练习"入口。
- [ ] 安全：Given 我访问个人中心，Then 只能看到自己的数据，无法越权查看他人进度。

## 模块六：社区与激励（远期）

### US-041 排行榜 `P2`
**作为** 一名 CTF 选手，**我想要** 看到积分排行榜，**以便** 和他人比较、获得竞争激励。

**验收标准**
- [ ] Given 多名用户有得分，When 我查看排行榜，Then 看到按总分排序的榜单（含我的名次）。
- [ ] 隐私：榜单仅展示用户选择公开的昵称，不泄露邮箱等敏感信息。

## 模块七：后台管理（远期）

### US-050 靶场内容管理 `P2`
**作为** 平台管理员，**我想要** 管理靶场（增改下线、配置难度/分值/预期漏洞点），**以便** 维护靶场内容。

**验收标准**
- [ ] Given 我是管理员，When 我新增/编辑靶场元数据，Then 列表与详情同步更新。
- [ ] Given 非管理员，When 访问后台，Then 被拒绝（权限控制）。
- [ ] Given 我配置靶场的"预期漏洞点"，Then 该元数据可供审查/测试作为对照基线。

### US-051 实例运维监控 `P2`
**作为** 平台管理员，**我想要** 查看当前运行中的实例与资源占用，**以便** 运维和回收异常实例。

**验收标准**
- [ ] Given 有运行中实例，When 我进入运维面板，Then 看到实例列表、归属用户、启动时间、资源占用。
- [ ] Given 某实例异常，When 我点击强制回收，Then 实例被销毁。
